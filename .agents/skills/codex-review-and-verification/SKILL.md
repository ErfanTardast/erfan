# Instructions

Run typecheck, unit tests, production build, static export when relevant, and
Playwright smoke tests. Verify homepage speed, mobile layout, hero fallback,
cart, quick view, wishlist, shop, PDP, reduced motion, imports, links, and old
brand removal. Report actual results only.

# Boundaries

Do not mark work complete when required checks are failing or were not run.
