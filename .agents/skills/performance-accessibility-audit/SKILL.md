# Instructions

- Audit mobile loading, image sizes, bundle cost, CLS, keyboard navigation,
  focus states, labels, contrast, touch targets, and reduced motion.
- Lazy-load noncritical images and prioritize only the hero asset.
- Preserve modal/drawer escape paths and focus behavior.
- Ensure motion never blocks product discovery and avoid unnecessary dependencies.

# Boundaries

Do not report assumptions as verified results. Run available tests and browser
checks and state any remaining gap.
